# [Thực hành] Sử dụng màu sắc trong trang web

Bài thực hành môn thiết kế giao diện web tại **CodeGym**: Phối màu đơn tông (Monochromatic Color Palette) cho giao diện trang web dựa trên màu xanh logo (`#00ADEE`).

## 🎨 Bảng màu đơn tông đã áp dụng
- **Bậc 1 (Màu chủ đạo):** `#00ADEE`
  - Dùng cho logo, nhãn ON SALE, nút và vòng tròn PREVIEW, đường dẫn navigation, các nút bấm CTA.
- **Bậc 2 (Điểm nổi bật):** `#00B2EF`
- **Bậc 4 (Màu nền banner):** `#90BFF2`
- **Bậc 7 (Màu nền nội dung/preview):** `#BDD7F7`
- **Bậc 9 (Màu nền footer):** `#C6E9FA`
- **Màu chữ:** Giữ màu đen (`#222`) cho toàn bộ trang để tối ưu khả năng tương phản và đọc nội dung.

## 📁 Cấu trúc thư mục
```
├── fonts/          # Các font pt-sans, pacifico
├── images/         # Hình ảnh giao diện và logo
├── index.html      # Trang chủ HTML
├── style.css       # File định kiểu CSS phối màu đơn tông
└── README.md
```
